# 스택(Stack)과 큐(Queue)

코드: `../code/stack.c`, `../code/queue.c`

## 핵심 비교

| 항목 | 스택 | 큐 |
|---|---|---|
| 규칙 | LIFO (후입선출) | FIFO (선입선출) |
| 넣기 | push (top에서) | enqueue (rear에서) |
| 빼기 | pop (top에서) | dequeue (front에서) |
| 시간복잡도 | push/pop O(1) | enqueue/dequeue O(1) |
| 오류 상태 | overflow / underflow | overflow / underflow |
| 구현 | 배열, 연결 리스트 | 원형 배열, 연결 리스트(head/tail) |

## 면접용 3문장 요약
- 스택은 한쪽 끝에서만 넣고 빼는 후입선출 구조로, 함수 호출 스택·되돌리기·괄호 검사에 쓰인다.
- 큐는 한쪽에서 넣고 반대쪽에서 빼는 선입선출 구조로, 작업 스케줄링·버퍼·BFS에 쓰인다.
- 둘 다 핵심 연산이 O(1)이고, 배열 또는 연결 리스트로 구현할 수 있다.

## 시험 포인트
- **스택 응용**: 함수 호출/재귀(콜 스택), 괄호 검사, 후위 표기식 계산, 중위→후위 변환, DFS, undo.
- **큐 응용**: 프로세스 스케줄링(라운드 로빈), 프린터 대기열, 버퍼, BFS.
- **원형 큐**: `(index + 1) % SIZE`로 순환. `front == rear`만으로는 빈/가득 구분이 안 되어 `count`를 두거나 한 칸을 비워 둔다(이때 가득 조건은 `(rear+1)%SIZE == front`).
- **덱(Deque)**: 양쪽 모두 삽입·삭제 가능. **우선순위 큐**: 우선순위 높은 것부터 나옴(보통 힙으로 구현).
- 후위 표기식은 피연산자를 스택에 쌓고, 연산자를 만나면 두 개를 pop해서 계산(먼저 꺼낸 것이 오른쪽 피연산자).
- 재귀가 너무 깊으면 콜 스택이 넘쳐 **스택 오버플로**가 발생한다.

## 직접 해볼 것
1. 연결 리스트로 스택 구현 (head 삽입/삭제 = O(1))
2. 큐 두 개로 스택 만들기 / 스택 두 개로 큐 만들기 (대표 면접 문제)
3. 중위 표기식(`1+2*3`)을 후위로 바꾸는 함수 작성
