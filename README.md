# wj — 공무원 7급 전산직 / CS 면접 대비 스터디

> 전공 과목과 면접 대비를 함께 공부하는 공간. 개념 → 직접 구현/실험 → 내 말로 정리.
> 시험 과목·일정은 변경될 수 있으니 사이버국가고시센터 최신 공고를 반드시 확인할 것.

## 폴더 구조

| 폴더 | 주제 | 핵심 키워드 |
|---|---|---|
| `01-data-structures-algorithms` | 자료구조·알고리즘 | 배열, 리스트, 스택/큐, 트리, 그래프, 정렬, 탐색, 복잡도 |
| `02-operating-system` | 운영체제 | 프로세스/스레드, 스케줄링, 동기화, 교착상태, 가상 메모리 |
| `03-database` | 데이터베이스 | SQL, 정규화, 트랜잭션(ACID), 인덱스, 동시성 제어 |
| `04-computer-architecture` | 컴퓨터 구조 | CPU, 캐시, 파이프라인, 명령어, 논리회로 |
| `05-network` | 네트워크 | OSI/TCP-IP, TCP/UDP, HTTP, DNS, 라우팅 |
| `06-information-security` | 정보보호 | 암호, 해시, 전자서명, 접근통제, 웹 취약점 |
| `07-software-engineering` | 소프트웨어 공학 | 개발 방법론, UML, 테스트, 형상관리 |
| `08-interview` | 면접 | 공공 IT 이슈, 개인정보보호법, 지원 동기, 모의 질문 |
| `09-mock-exam` | 모의고사 | 기출/예상 문제, 오답 노트 |

각 폴더: `notes/`(정리 노트, Markdown), `code/`(실습 코드, 해당되는 과목만).

## 학습 방식

1. **개념 읽기**: 교재/강의로 핵심 개념 파악
2. **직접 해보기**: 코드 구현이나 명령어 실험 (`code/`)
3. **3문장 요약**: 면접 답변처럼 내 말로 정리 (`notes/`)
4. **퀴즈/모의 면접**: Claude에게 질문을 내달라고 요청하고 피드백 받기
